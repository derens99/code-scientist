# Boundary contract

* `format_number`: `value` accepts finite `int`/`float` except `bool`; invalid type raises `TypeError("value must be an int or float")`, non-finite raises `ValueError("value must be finite")`. `decimals` must be a non-negative `int` (`ValueError("decimals must be a non-negative int")`); `width` must be a non-negative `int` when supplied (`ValueError("width must be a non-negative int")`).
* `split_record`: `sep` must be a one-character string other than `"` (`ValueError("sep must be a single non-quote character")`). Unterminated quotes raise `ValueError("unterminated quoted field")`; non-separator data after a closing quote raises `ValueError("unexpected data after closing quote")`.
* `merge_intervals`: each item is a 2-element tuple/list (`ValueError("each interval must be a 2-element tuple or list")`); endpoints must be `int` (`TypeError("interval endpoints must be int")`); descending intervals raise `ValueError("interval start cannot exceed end")`; `lo`/`hi` when supplied must be `int` (`TypeError("lo must be int")`/`TypeError("hi must be int")`) and `lo > hi` raises `ValueError("lo cannot exceed hi")`. Empty and clamped-empty intervals are omitted.
