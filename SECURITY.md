# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository:

https://github.com/derens99/code-scientist/security/advisories/new

Include the affected command or route, a minimal reproduction, impact, and any
suggested mitigation. Please avoid including real credentials, private corpora,
or other sensitive data in the report.

The project is a local research tool. Validation processes and agent executors
are not a security sandbox, and the workbench should not be exposed directly to
untrusted networks.
