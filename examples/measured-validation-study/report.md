# Code Scientist Research Report

Objective: Find the single appended system-prompt instruction that most improves a small headless coding agent's held-out-test pass rate on short self-contained Python implementation tasks whose prompts do not themselves instruct testing or verification. Hypotheses must be A/B-testable (baseline: no appended instruction; candidate: baseline plus exactly one instruction) and grounded in observed small-model failure modes: incomplete extraction of listed requirements, unverified edge cases, and premature completion.
